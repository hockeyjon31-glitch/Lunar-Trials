# Post-Apocalyptic Bike B – Documentation

## Overview
This package includes a high-quality **post-apocalyptic bike model** designed for real-time applications such as games, cinematics, and simulations.

The asset supports multiple Unity render pipelines and comes with **clean and dirty texture variations**, allowing you to easily adapt the bike’s appearance to different environments and storytelling needs.

---

## Render Pipeline Compatibility

This asset is fully compatible with:

- Built-in Render Pipeline (BRP)
- Universal Render Pipeline (URP)
- High Definition Render Pipeline (HDRP)

Each pipeline includes properly configured materials.

---

## Technical Details

- **Vertices:** 20,805  
- **Triangles:** 22,555  
- **Meshes:** 5  
- **Materials:** 3 per render pipeline (Body Clean, Body Dirty, Engine)  
- **Textures:** 12 (Base Color, Normal, MAS, AO)  
- **Texture Resolution:** 4096 × 4096 px  
- **Rigged:** Yes  
- **Animations:** No  
- **UV Mapping:** Yes  
- **LOD:** No

## Setup Instructions

1. Import the package into your Unity project.  
2. Ensure your project is using one of the supported render pipelines (BRP, URP, or HDRP).  
3. Open the prefab located in the package folder.  
4. If needed, select the correct material variant for your render pipeline.  
5. Drag and drop the bike prefab into your scene.
